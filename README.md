## 📌 Overview
SafeRide is a comprehensive, cloud-centric mobile ecosystem designed to ensure the utmost safety of students during school transportation. By combining a cross-platform mobile application with an AI-driven safety engine, SafeRide provides real-time tracking and active driver monitoring without the need for expensive external hardware.

## ✨ Key Features
*   **📍 Real-Time GPS Tracking & Geofencing:** Utilizes native smartphone sensors to provide zero-hardware-cost, real-time location updates and geofencing capabilities.
*   **😴 AI Driver Drowsiness Detection:** An integrated AI engine that actively monitors driver safety by calculating the Eye Aspect Ratio (EAR) to detect signs of fatigue or drowsiness.
*   **🚨 Emergency SOS Alerts:** Instant SOS notification system for immediate response during emergencies.
*   **☁️ Cloud Synchronization:** Seamless real-time data synchronization across the ecosystem powered by Firebase.

## 🛠️ Technology Stack
*   **Frontend/Mobile App:** Flutter, Dart
*   **Backend & Database:** Firebase (Realtime Database / Firestore, Authentication)
*   **AI/Computer Vision:** Python, Dlib, OpenCV (EAR calculation)
